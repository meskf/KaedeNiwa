# PWA / 移动端真机验收清单

- 日期：2026-10-22
- 目标：iOS Safari / Android Chrome 上作为 PWA 安装并完成基本聊天流程

## 安装与离线

- [ ] `manifest.json` 可访问，Chrome DevTools → Application → Manifest 无报错
- [ ] Android Chrome 出现“安装应用”；iOS Safari 分享 → “添加到主屏幕”
- [ ] 安装后以 standalone 启动，状态栏与安全区不遮挡顶栏/底部 Tab
- [ ] 断网后重新打开：壳（HTML/CSS/JS/WASM）从 Service Worker 缓存加载
- [ ] 断网时首页可渲染，显示登录/离线提示，不出现白屏
- [ ] 联网后自动恢复；API 与 WS 不被 SW 缓存（消息始终新鲜）

## 文本与消息

- [ ] 登录/注册成功，频道列表与消息历史正常
- [ ] 发送文本、回复、表情反应正常
- [ ] 未读红点与 @ 高亮正常；打开频道后未读清零
- [ ] 本地搜索可从移动顶栏 🔍 打开，输入中文/英文能命中
- [ ] 附件上传：进度条出现并到达 100%；图片显示缩略图，点击可下载原图
- [ ] 键盘弹出时输入框不被遮挡（`interactive-widget=resizes-content`）
- [ ] 横竖屏切换后布局不溢出、无横向滚动

## 语音 / 屏幕共享

- [ ] Android Chrome：麦克风授权后能开麦/关麦
- [ ] iOS Safari：麦克风授权后能开麦/关麦
- [ ] 不支持屏幕共享的浏览器（iOS Safari）点击“屏幕”给出明确提示
- [ ] Android Chrome：屏幕共享可用，分辨率跟随画质档位
- [ ] 语音通话中切后台/回前台，音频不崩溃（浏览器允许范围内）
- [ ] 离开语音后麦克风指示灯熄灭

## 安全与恢复

- [ ] 同账号在另一设备登录后，旧设备被踢下线
- [ ] 设置 → 登录设备：列表正确；撤销其他设备后其 token 失效
- [ ] 私密频道：密码错误提示清晰；加入后可看成员；op5 可移除成员
- [ ] 网络切换（Wi-Fi ↔ 移动数据）后自动重连，离线事件补投
- [ ] 刷新页面后 MLS 快照恢复，历史消息不重复/不丢失
