【这是什么】
一个 Rust 原生的端到端加密（E2EE）实时协作平台。
消息走 MLS (RFC 9420)，媒体走 LiveKit + SFrame，服务器零解密。

【怎么启动】
1. 解压本目录到一个空位置（路径不要有空格或中文，例如 D:\kaede）
2. 双击 start-kaede.bat
3. 等约 5 秒，会弹出 KaedeNiwa 桌面窗口
4. 登录页的「服务器地址」预填了 http://127.0.0.1:18080，直接注册账号即可

【怎么退出】
- 正常：关闭 KaedeNiwa 桌面窗口，服务会自动停止
- 卡死：双击 stop-kaede.bat，强制停止所有进程

【首次使用会创建】
- data\kaede.db        ← 你的本地数据库（消息密文 + 元数据）
- data\attachments\    ← 附件存储
- logs\server.log      ← 服务端日志
- logs\livekit.log     ← 语音/视频服务日志
这些文件不会自动删除，重启后数据保留。

【你的身份】
- 第一次注册的账号 = 你的主人账号
- 数据库保存在 data\，所以换电脑要备份 data\ 目录
- 服务器密钥组: LIVEKIT_API_KEY={{LIVEKIT_KEY}}
  （config\.env 和 config\livekit.yaml 里都有，请勿外传）

【让朋友连进来（可选）】
默认只允许本机访问。要让局域网内朋友用同一服务器：
1. 编辑 config\.env:
   - KAEDE_BIND=0.0.0.0:18080
   - LIVEKIT_WS_URL=ws://你的局域网IP:7880
   - KAEDE_CORS_ORIGINS=http://你的局域网IP:18080
2. 编辑 config\livekit.yaml:
   - rtc.use_external_ip: true
3. 防火墙放行: 18080, 7880, 7881, 7882-7892 (UDP)
4. 重启 start-kaede.bat
5. 朋友登录页「服务器地址」填 http://你的局域网IP:18080

【遇到问题】
1. 双击 start-kaede.bat 后窗口一闪而过:
   右键「以管理员身份运行」再试一次。
2. 提示"缺失 WebView2":
   下载安装 https://go.microsoft.com/fwlink/p/?LinkId=2124703
   （Win10 1803+ / Win11 已内置）
3. 语音/视频无声或黑屏:
   看 logs\livekit.log，常见是防火墙拦住 7882-7892 UDP 端口。
4. 数据损坏想重来:
   关闭程序，删除 data\ 和 logs\，重新双击启动。

【隐私说明】
- 所有消息和媒体端到端加密，服务器只存密文
- 服务器不知道你的消息内容，只知道谁在什么时间发了多少字节
- 数据库存在你自己的电脑上，随时可删
- 密钥存在系统的凭据管理器（DPAPI），不写明文到磁盘
